## 沿用的使用者手動驗證與未驗證事項

**使用者先前手動驗證**：啟動器雙擊可見視窗；合成加密檔確實落地；在獨立空白瀏覽器設定檔還原、重開保留及再次備份。這些沒有在本輪重新執行，不計入上述通過數字，也不是正式帳本搬移。

本輪仍未驗證：原生下載檔落地／從該檔還原、全新瀏覽器設定檔的完整閉環、整個瀏覽器程序結束重開、實體手機／其他瀏覽器、真實配額耗盡／裝置故障、真 OAuth 與正式帳本。布局實測限上述核心記帳操作，不宣稱每一設定表單均完成 375px 手動操作。

最小下一步為**在選定的實際瀏覽器，以新的合成設定檔完成檔案復原演練**：固定網址建立合成帳本 → 加密下載並確認檔案存在 → 另一全新空白設定檔從該檔還原 → 核對九類資料 → 關閉／離線重開 → 再備份。不需先增加產品功能，也不要清除原設定檔。若沒有可用備份或帳本開啟失敗，先停止查明，不覆蓋／強行還原。

本機 IndexedDB **未加密**；備份密碼只保護備份檔、遺失不能取回，不能抵禦已解鎖電腦、本機惡意程式或瀏覽器擴充套件。持久保存獲准仍可能遺失。未 stage、commit、push 或更新 PR。
