2026-10-17，適用0.27.0。使用者核准A「柔和日常＋抽象太陽」、四區、D01～D04及五項UX整合，以此先完成全站再集中微調。本文件是唯一正式視覺／呈現規範；[工作流程](ui-ux-workflow.md)管理分工與授權，帳務真相仍依原功能規格與核心。原始候選為`.tmp/ui-ux-a-site-20261017/preview.html`與候選說明，本文件保存實作所需內容，忽略目錄不是唯一依據。

## 視覺與共用元件

- 品牌：日餘／讓生活有度。偏心圓面與開口圓弧是本版抽象太陽標記，非最終Logo定稿；只在品牌位置，不增加裝飾動畫。
- 色彩：背景`#F5F3F1`，表面白，主操作`#61546F`，淡選取`#EFEBF2`，主文字`#29262E`，次文字`#625D68`，控制邊界`#8E8797`，分隔`#DED9E0`。收入／成功`#276451`、支出`#77472D`、警告`#79520D`、錯誤`#A62E3D`；搭配文字／符號，不能只靠顏色。品牌短弧`#A67B2E`不作功能文字。
- 系統繁中字體：system-ui、Microsoft JhengHei、PingFang TC、sans-serif；不下載。內文16px／1.65、標籤14px、輔助13～14px、頁標題28／窄版24、區標題20／18。重要金額不為版面縮小；等寬數字、千分位、元、整數不帶.00，既有精度不變。
- 間距4／8／12／16／24／32，內容寬1080px、桌面邊28／窄版14；面板24／16。面板圓角12、按鈕10、欄位8、標籤6；以邊界區分，只有分段選取可用微陰影。
- 主動作實色、次要描邊、查看／返回短文字。控制至少44px高，長名稱可換行，3px焦點外框及間隔；原生表單、details及dialog優先。日期及金額錯誤對應原欄位，失敗保留輸入。
- 列表保持資料密度與行內單筆操作；表格必要時內部水平捲動，頁面本身不溢出。圖表使用灰紫／青綠／赭褐，保留完整精確文字、圖例與表格；不刪圖表選擇能力，不新增重複圖表。
- 轉場僅必要狀態140ms，可中斷、不阻塞輸入；減少動態時停用。不固定浮動工具列，不遮擋焦點。

## 核准任務與狀態

- 四區記帳／規劃／分析／設定。記帳與搜尋不可隱藏；其餘首頁顯示、排序、捷徑數量、收合偏好沿用，節點移動不重建表單或清空草稿。
- 新增支出「記錄消費」、新增實收「儲存收入」、既有帳目「儲存更改／儲存收入更改」、定期草稿「記錄消費／確認已收到並儲存」。顯示對象、來源與取消／完成返回脈絡，沿用入口別草稿快照與選取政策。自動來源已記錄日期仍唯讀。
- 空帳本保留原表單，帳目列表顯示尚無記錄；搜尋零結果保留條件。首次只需開始／還原，不要求收入、目標或登入。
- 搜尋選取0筆動作不可用且不展開；1筆單筆更改完整欄位；2筆以上批次更改分類／付款／標籤，不改金額。全選完整符合支出，排除收入。作用範圍、筆數、取消清楚；保留原批次確認、revision、rollback及返回規則。
- 規劃先四個精簡入口：生活預算、收入與每月分配、定期支出、存錢目標，再展開待確認收支。記帳提供直達規劃。到期預計、實付、分配、目標與實收不混用；現有規則、期數及歷史功能全部保留。
- 總預算欄位旁有獨立儲存／清除，分類各自保存；無須展開分類保存總額。未儲存／儲存中／成功／失敗區分，失敗保留輸入，不新增整頁保存、自動保存或交易契約。
- 分析保留現行期間比較預設；僅當前期間比較／標籤頁加一句短問題。摘要→主圖→精確統計／每期明細；兩種平均各有分母：所有已開始期間含零、有消費期間排零。未來不列分母，零分母無法計算，未結束截至今天，計算及四捨五入不變。每月收支及既有指定日期比較不硬加平均。
- 設定第一項編輯首頁是精簡可展開入口，原控制保留；分類、付款、標籤順序不變，資料管理最下面。說明集中，資料風險與必要確認保留原操作處。
- 提交前失敗可修正重試；提交後畫面失敗須明示操作已完成、畫面未更新、勿重複提交、寫入鎖定與重新載入確認，不能仍顯示尚未記錄或宣稱回滾。
- 分析預設改動、分析轉接搜尋、捷徑覆寫與返回政策一致化未核准，維持現況。Web與未來App共用語意，不指定框架。
